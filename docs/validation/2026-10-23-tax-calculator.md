# 税务计算验证记录

## 验证目标

实现规格见 `docs/specs/2026-10-23-tax-calculator.md`。验收以实际 CSV 经页面上传后的服务端计算为准，不以格式校验或手算代替集成验证。

## 当前状态

2026-10-24：开发与本地验证完成，生产发布待执行。先写规格和验证方法，再实施；未将私有基准或真实资料写入公开仓库。

## 自动化测试

- CSV：BOM、引号／换行、表头别名、日／秒精度、账号与代码前导零、负数、精度、行号错误、不支持期权、金额关系。
- FIFO：跨年成本、部分平仓、一笔卖出对应多个买入、多头／空头、基金赎回、跨账户历史、日期筛选、真正的缺少开仓、零余额精确消耗。
- 汇总：全部当年费用、费用退款、股息、出入金和空原因区分；原币分项、人民币换算、亏损不跨年、股息估算、汇率缺失及舍入次序。
- 存储／API：导入预览无写入、确认幂等、重复批次、重叠行多重集、删除后保留其他来源、空间隔离、大小限制、错误响应、服务启动关闭。
- 前端：上传预览与确认、请求失败重试、日期／账户过滤、视图切换、配对详情、汇率编辑、批次删除及导出。
- 必要回归：Go 检查与测试，前端类型检查、测试、格式及构建。

## 真实年度 CSV 对照

测试输入从外部私有目录读取，不复制进仓库。2020—2025 资料范围内实际有 2020、2021、2024、2025 四个年度 CSV；2022、2023 年现有年单无流水，不生成伪造空文件。四份 CSV 共 284 条记录。

在隔离本地测试数据库启动应用，通过真实文件选择控件上传全部年度文件，确认导入，刷新页面确认持久化。随后读取 UI 和 API 结果，并核对：

1. 文件／记录／账户数，重复上传同一文件后的不变性。
2. 各年度、各币种：匹配卖出收入和买入成本、赎回与申购、交易费用、其他费用、净利润、股息。
3. 各年度人民币：净利润、股息、交易税额、股息估算税额和合计税额。
4. 每项使用截图可辨认精度比较；截图以“万”缩略的金额不能虚称已经逐分核对。
5. 2025 年两条基金赎回在精确计算后不产生虚假零数量缺口；真实缺口用合成数据单独验证。
6. 2024 旧账户 NIO 买入与升级后账户 2025 卖出必须衔接；配对详情可追溯原账户。
7. 日期过滤仅改变展示的所得期间，不能丢失前置买入。
8. 修改汇率后结果相应变化，恢复后与基准再次一致。
9. 导出内容与当前显示范围、精度和计算结果一致。

精确截图基准保存到私有目录，自动对照输出按字段记录 expected、actual、difference。两位金额要求差额为 0.00；差异不得通过硬编码用户金额消除。若平台显示舍入、成本范围或其他规则存在差异，先定位并记录，再修正计算或明确说明。

## 执行结果

### 自动化

- `backend/`: `make check` 通过（gofmt、包含 e2e 编译标签的 go vet）；`make test` 通过（全包、race、随机顺序）。未执行真实上游采集或生产 E2E。
- `go test -race -v ./internal/modules/tax ./internal/app` 配合外部私有 CSV 和基准文件通过；税务新增 6 组常规测试及 1 组真实年度回归。
- `frontend/`: `npm test` 全部 35 个测试文件、320 项测试通过；`npm run build` 和 `npm run format:check` 通过。
- 前端测试最初受 Node 全局 localStorage 实现影响；测试中改用隔离存储后，全量重新执行通过。导入失败信息被刷新清除的问题也已修复，并有失败后重试用例覆盖。

### 真实导入与数值

- 在独立本地服务及临时数据库启动 `/tax`，用浏览器文件控件实际选择四份真实 CSV，逐个预览并点击确认导入。输入副本仅暂存到允许访问的私有系统临时目录。
- 页面与 API 均为 4 个导入批次、284 条去重后流水，年度汇总 10 行。
- 私有截图基准包含 73 个参考字段（其中 53 个金额字段，其余为年度、币种标识）；后端真实回归与浏览器上传后的 API 比较均全部一致，金额差额为 0.00。
- 基金两处零数量缺口未复现，真实数据的缺少开仓列表为空。真正缺少开仓的合成用例仍会报告非零缺口。
- 跨账户历史成本已正确配对；将显示区间限制为 2025 年，三行年度汇总与全期间中的相应结果一致。
- 再次通过文件控件上传全部四份 CSV，预览新增均为零；确认后仍是 4 个批次、284 条记录。浏览器整页刷新后数据保留。
- 浏览器展开年度成本明细成功；通过汇率表单修改再恢复汇率，结果随之变化并恢复。
- 从真实“导出年度汇总”操作取得生成的 CSV 内容，解析得到 10 行；53 个金额字段与原截图基准再次全部匹配。CSV 文本公式转义另有单元测试。
