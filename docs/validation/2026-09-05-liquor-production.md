## API 与服务保护

| 只读检查或安全探测 | 结果 |
| --- | --- |
| 最新列表与所有酒品历史 `limit=366` | 11 个产品均为 200 JSON，共 341 条，字段、金额、日期和最新点一致 |
| 同日起止日期、`limit=1` | 包含端点且仅返回对应最新一条 |
| 无效日期、反向日期范围、重复 limit、limit=0/367 | 400 JSON，`invalid_query` |
| 不存在的酒品、未知行情 API 路径 | 404 JSON，没有回退成页面 HTML |
| POST 同步，使用无效请求体 `{"e2e_readonly_probe":true}` | Nginx 返回 403 HTML；无效请求体即使到达 Go 也不应启动任务，未使用合法 `{}` 触发同步 |
| 同步状态前后对照 | 任务 ID、成功时间、报价日期和记录数均未改变，未观察到测试触发采集 |
| 公网 Go 5051 健康探测 | 三秒内无 HTTP 响应，说明测试客户端当时不可直达；Compose 亦无该宿主机端口映射 |
| 原微博 5050 | 统计接口返回 200，只核对状态，不输出私有数据 |

最终服务器检查：三个容器均运行，重启计数 0、无 OOM。一次空闲内存采样为微博约 55.8 MiB、Nginx 3.4 MiB、Go 5.8 MiB；不是运行峰值或容量保证。
