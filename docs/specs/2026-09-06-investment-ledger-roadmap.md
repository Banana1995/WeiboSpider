## 4. 各项交付标准

### T01 总资产账户持续记账

**目标：导入旧账后可以直接在本系统继续记录，不必回原应用再导出。**

- 支持不依赖 Excel 新建总资产账户；支持“记总资产”“转入/转出”和投资日志，资金流记录可同时提供总资产。
- 支持账户级记录更正、作废和修订历史，保留原始导入内容，通过有效记录视图体现修改，不直接篡改原文件快照。
- 导入与手工记录共同出现在账户级列表；最新资产、日期和相关摘要按有效记录更新，并明确“原始导入统计”和“当前有效统计”的区别。
- 不生成股票买卖、不关联持仓、不把总资产当现金，不因账户级转出触发持仓现金不足校验。
- **验收：**导入后新增资产和资金流、更正/作废导入及手工记录、版本冲突、重复提交、缺失与零、同日多条、失败回滚均通过；重新上传原文件不能抹掉后续修订或重复资金流。已有持仓账户行为不回退。
- **本项不做：**不同导出版本合并、走势图或收益率。

### T02 分析口径与更正影响

已确认（2026-09-08 修正每日选点）：同日资产为 post-flow，按 date + 稳定 sequence 取当天最后明确资产，后置资金流不覆盖；无明确资产才取最后非日志沿用/缺值依据，weekly_carry 非新观察，人工确认例外。缺资产资金流的逐条明细仍只沿用前值，不加款、不取未来值、不写伪观察。首条明确资产无资金流是有效基准，不虚构本金。所有来源统一分析，reported/holdings 只表示自动计算能力，HTTP 不接受 track。公网边界不变。

- 唯一分析输入是 account_records 的当前有效金额；审计仅追溯与验证来源，不从历史审计重建金额。
- 确定期初资产、期间边界、转入转出符号、日期/时区、同日多条的展示与计算顺序。来源行号、创建时间不自动等于真实业务先后。
- 为原始估值、有效记录和派生分析建立可追溯关系；补记、更正、作废后标出受影响区间和待重算状态，原始估值不覆盖。
- **验收：**无期初资产、流量有值但资产缺失、同日组合行、延后补记、混合数据来源及更正后过期结果均有明确规则和合成用例；不能计算时说明原因，不补零。
- 已有失效追踪保留，但不再承诺通过 T06 自动修复旧持仓总额。账户级分析直接使用更正后的有效总资产与资金流；收益曲线的相应更新在 T07 验收，不另建行情重算服务。

### T03 总资产走势图

- 每个账户展示全部有效导入、人工、操作腿及自动总额，同一列表和资产图；保留日期范围、点选详情、日志和资金事件。
- 同日多条保留详情；图上若聚合为单点，要说明选取规则，不删除底层记录。没有估值的资金事件不伪造一个资产点，数据缺口不插值冒充真实记录。
- **验收：**图、列表、接口日期和金额一致；空区间、同日多条、缺失数据、过期序列、快速切换及桌面/移动端点选通过。
- 这一阶段只展示资产走势，不标成收益率或投资收益。

### T04 累计收益与资金加权收益

- 实现累计收益、Modified Dietz 区间收益及 XIRR 年化，与期初/期末资产及外部现金流共同解释；买卖不能重复当作外部投入。
- 确定日内权重、日数、区间边界与年化约定；处理零分母、亏损、缺失资产、XIRR 无解/多解/未收敛等情况。
- **验收：**纯入金无收益、入金买入不重复核算、出金、分红、闰年、零收益及失败求解都有固定案例；原值精确保存，展示舍入不反向污染计算。私有样本核对另按 G01 执行，不能以合成测试替代真实对账。

### T05 每周六更新总资产

- 每周六处理所有账户。对已有当前现金、持仓及可用报价的账户计算并保存一笔总资产；无自动计算来源的账户复制计划日以前最近一笔有效总资产。用户已确认北京时间（Asia/Shanghai）08:00；自动功能默认关闭，须显式启用。记录实际价格/汇率日期或被沿用记录日期，不将周五报价或旧金额说成周六新行情。
- 历史和后续总额直接写同一账户同一张表；不设来源切换、桥接、选择器或模糊去重，不反推历史股数或成交。原始内容、修订及报价证据仅存统一 audit_log。
- 没有自动总额来源的账户仍可随时手工更新；周任务使用 `weekly_carry` 新记录保存原金额，同时冻结原始记录 ID、版本、日期和金额。该记录明确显示为沿用，不冒充持仓、现金或新行情；没有任何历史总资产时才 `skipped/no_source`。导入历史不要求绑定持仓，也不新增目标提醒或推送功能。
- 周任务按账户和计划日期去重。交互 GET/HEAD 只读，显式 POST 按幂等键保存；原提交重试不获取新报价、不恢复后续人工修正。保留旧导入、手工和旧刷新观察，不做全局同日去重。
- **验收：**成功新增自动估值或沿用总资产记录并可用于曲线；沿用详情能显示原始金额与日期且不请求估值历史；重启/重试不重复完成同一计划任务；无历史金额、行情缺失、部分报价、休市均有明确状态；不触发历史采集，不产生独立事件日前后任务。本轮仅完成定向测试，统一验收稍后执行。

### T06 已取消：历史行情回填与资产重建

- 不采集历史股价/汇率以重建账户历史总资产，不回溯分红、拆股或送股；这些已体现在导入总额中。
- 删除 T07 等任务对 T06 的依赖。T02/T04 已有按有效记录重新计算的行为保留；后续曲线更新归入 T07，不把原任务改名后继续建设。
- 旧自动总额受操作更正影响时显示需要核实或修正；本轮已移除 T06 重算承诺。人工修正金额可作明确记录，原始报价证据仍保留。

### T07 收益曲线与时间加权收益

- 直接使用导入及后续有效总资产、转入/转出记录，完成累计收益金额曲线、资金加权收益率曲线、TWR/复利年化和视角切换；不再要求股票历史价格或历史分红明细。
- 按已确认日终公式 `(当日资产-当日净资金流)/上一资金边界资产`，在非零外部资金事件日链乘（同日进出抵消仍要求边界）；普通观察不永久链乘。来源和参考值状态保留，不要求另外采集历史事件前后的市场报价。
- 更正、作废或新增记录后，从当前有效记录重新计算指标及曲线，与从头计算一致；不覆盖原始导入或伪造历史总额。更新已取消 T06 的旧提示文案。
- **验收：**只使用总资产和资金流的合成导入即可得到相应收益图，无行情请求；纯转入/转出且总额同步更新时不产生虚假投资收益；无起点、零分母及沿用参考等状态明确。曲线点位与同区间指标一致，不拿 Modified Dietz 冒充 TWR。

### T08 多账户汇总

- 支持一个账户属于多个汇总，“全部资产”按底层账户去重；汇总引用历史，不复制资金流水。
- 回溯成员全部有效历史，成员从自己的首次记录纳入；调整成员后重算。对非同步估值沿用已确认的暂估规则并标明，不引用未来值。
- 只抵消明确关联、双方均在范围内的转账；不根据导入日志或金额相似性自动关联。
- **验收：**成员交叉、不同起点、手工与自动账户混合、包含转账一方/双方以及成员变化均不重复资产或扭曲投入。

### T09 基准与年度对比

- 核验沪深300全收益等候选来源，确定首批名单、价格/全收益口径、币种折算、日期对齐及比较方式后再接入。
- 增加年度收益表、账户/基准曲线和选择器；缺失基准数据保留缺口。
- **验收：**价格指数不冒充全收益指数；首年、今年及自定义区间与单账户结果一致，同日缺失不使用未来基准点。

### T10 已取消：增量导入与批次撤销

- 保留已有一次完整批次导入、相同内容幂等重试、预览确认及逐条新增/更正/作废，不删除已实现能力。
- 不增加不同文件版本合并、增量更新或整批撤销。T11 不再依赖本项。

### T11 账户管理与导出

- 增加账户名称/目标/备注等适用设置及归档，明确归档对汇总的影响。账户币种不能通过普通编辑重新解释旧金额。
- 提供业务数据导出，区分原始记录、有效记录、修订和估值来源；必要的文件格式、安全转义及再导入边界须明确。
- **验收：**归档不删除历史，导出可核对数量和金额且能区分 null/零。永久删除、期初更正或币种迁移若需要，应另行设计，不能用清空数据实现。
- SQLite 运维备份不等待本项，见 G01。

### T12 移出排期：复杂金融事件

- 历史分红、拆股、送股已包含在导入总资产中，不追溯、补入或再次计收益。
- 跨币种转账明确不做；已有同币种等额转账及持仓/交易汇率折算保留，它们不是跨币种转账扩展。
- 未来自动分红等未实现扩展只保留为历史讨论，不列本轮待办或收益分析前置；已有手工分红继续可用。如日后确需扩展，再由用户明确提出。

### T13 目标规划与预期曲线

- 保留目标规划及预期曲线，实施时明确目标金额、期限、预期收益等参数及计算假设，不把未确认的复杂规划功能自动加入。
- 目标提醒、通知及分享暂不做，不作为账户设置或规划的前置。
- **验收：**预期曲线随规划参数变化，可与已记录实际资产/收益区分；清楚标识为情景假设而非已实现收益或收益承诺，不写回真实账本。完整登录、注册和角色系统仍不列为一期强制前置。
