# 账户组合：成员选择、合并收益与贡献

## 已确认的产品口径

- 用户保存多个命名组合，自行选择成员；同一账户可以参与多个组合。
- 使用横向组合标签切换，支持键盘左右键/Home/End、手机横向滚动；成员在弹窗里搜索、多选。
- 主区通过「整体表现 / 账户贡献」切换。年度收益、计算依据和资金记录按需展开。
- 组合支持 CNY/HKD/USD 混合成员，组合展示币种可在新建/编辑时设置，新建默认 CNY。资产、资金流、收益按本次最新可用汇率统一折算；历史曲线及年度分析使用同一组当前汇率，不计历史汇率波动收益。不识别内部转账。
- 编辑组合成员后，以当前成员集合重新计算历史，没有成员加入/退出生效日期。
- 从最早有财务记录的成员开始：A 在 2021 年开始、B 在 2023 年开始，则 2021～2022 年只计 A。
- 后出现的成员带入期初资产；带入是分析调整，不能当作投资收益或新增原账户流水。
- 未更新总资产时，以最近总资产加后续净转入计算，假设期间无投资涨跌；后续总资产更新在更新日体现差额。
- 默认个人视角：资金加权收益率为 Modified Dietz，年化为 XIRR。基金经理视角复用 TWR 和复合年化。

算法参考：[有知有行：详细了解两种账户观察视角](https://youzhiyouxing.cn/materials/1277)。公式同类不代表已验证与第三方所有日期边界、舍入及汇总规则逐项相同；实际对账需要同一组账户、同一截止日及完整流水。

## 数据与一致性

`003_portfolios.sql` 在当前 `001_init.sql`、`002_account_deletion.sql` 基础上增量迁移，增加 `portfolios` 并扩展全局幂等回执的对象类型。已有账户、历史记录、审计及回执保留；不重写既有迁移，也不重置数据库。

组合只保存名称、币种、成员 ID 集合、版本及时间；财务事实仍来自各账户当前有效 `account_records`。组合没有独立持仓或行情采集任务。一次分析在同一 SQLite 事务中读取组合定义及所有成员投影，事务结束后计算收益，避免拼接不同修订时点。

跨币种分析在释放事务后调用现有腾讯汇率服务；每种外币每次分析查询一次，汇率、日期、来源随分析返回并参与修订摘要。先将明确资产及每笔资金流精确折算到分，再沿用并合并；账户原始记录不改写。无法取得有效汇率时返回错误，不返回部分账户合计。旧组合币种及省略币种的旧同币种写入回执保持兼容，无需数据库迁移。

新增、修改、删除组合与审计、全局 Idempotency-Key 回执同事务提交。修改/删除使用 `expected_version`；网络重试复用原字节和键。删除组合保留原账户；原账户被删除后，组合定义保留该成员，分析返回 `portfolio_member_missing`，由用户调整成员后继续，不能静默改变统计范围。删除的组合 ID 由审计保留，不可重新使用。

## 合并规则

1. 按自然日和已有稳定序号整理各成员，作废与未来记录不参与。
2. 同日采用最后一笔明确总资产；它已经包含该日全部资金流，不能再加一次。同日单笔资产字段为空的后续资金记录也遵循这一规则。
3. 首日有明确资产时，期初带入为 `max(首日资产 - 首日净转入, 0)`。首日净转入超过资产的差额保留为该日亏损，不能用负的期初带入抵消亏损。
4. 首日只有资金流时，从零加净转入开始，并标为推算。任何阶段若无法得到非负资产，则返回 `portfolio_basis_missing`；无财务记录的成员在该区间贡献为零，界面标明尚无记录。
5. 后续未更新日沿用最新明确总资产，加其后的净转入。周六沿用记录不成为新的明确资产基准。
6. 合并日期取所有成员资金/资产日期的并集，并补充所需年末、区间边界。成员未开始前不计入；每个日期的总资产和净资金流分别加总。
7. 截止日不超过所选成员最新有效财务日期。选择其之前的自定义截止日时，可按约定沿用规则补齐边界；年度年末与同日自定义查询使用相同投影。
8. 总资产、收益、曲线均来自这一份组合投影。资产曲线用阶梯线表达沿用，成员首次计入用图上标记说明。

所有金额使用整数分与大整数中间结果，返回十进制字符串。图表坐标才转换为 Number；显示金额、合计和百分数不经浮点复算。

## 收益与成员贡献

- 组合收益 = 期末资产 − 期初资产 − 区间净流入，期初带入包括在组合资金流中。
- Modified Dietz、XIRR、TWR 及曲线复用单账户计算器；沿用既有日数口径：`period_days=自然日日差+1`、流量权重日数为 `期末日-资金流日`。
- 组合的首日全部资金流已包含在期初资产中，默认全历史计算排除首日流量，避免重复投入。
- 年度收益逐年计算，不能相加年度百分比，或把各成员收益率做平均。
- 成员展示期末资产、资产占比、区间收益及自身收益率，展开可看年化、实际统计区间和最近明确资产日期。
- 收益金额按组合的同一边界与流量分摊，合计必须等于组合收益；较晚加入的成员的首次计入日亏损也属于其金额贡献。
- 成员自身收益率以该成员的资产基准计算，可能从晚于组合的日期开始。它不是组合收益率的贡献百分点。
- 所有估算带 `portfolio_carried_assets` 说明；XIRR 不可解/多根风险等继续使用现有明确的不可计算原因。

### 合成验证例

A：2021-01-01 资产 10,000，2021-06-01 资产 10,500，2022-01-01 资产 11,000，2022-01-03 资产 12,100。

B：2022-01-01 首次资产 20,000，2022-01-02 转入 5,000，但未填总资产。

组合从 2021 年开始；B 计入前与 A 相同。B 首次带入 20,000，之后资产按 25,000 沿用。期末总资产 37,100，组合收益 2,100，分别来自 A 的 2,100 与 B 的 0。
