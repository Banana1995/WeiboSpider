# 投资账本后续修正验收

## 需求覆盖

- XIRR：多次转入转出时继续求候选根，再以折现累计现金流验证全局唯一性，保留独立舍入认证。详见 [求解说明](../specs/2026-10-25-ledger-xirr.md)。
- 买入表单：不显示实时“买入支出”预览；保存时的精确金额校验仍有效。买入、加仓、补录初始买入及修改买入记录共用该规则。
- 保存反馈：持仓买卖、分红等编辑正常提交时在按钮显示“保存中…”，保留屏幕阅读器状态，不插入大块提示；仅请求结果不确定时显示原请求重试入口，保留锁定、原请求字节和幂等键。
- 持仓详情：点击股票打开原生居中弹窗，背景保留列表；包含行情、现金、持仓指标、买卖与分红流水、修改/删除、已删除记录筛选、计算说明和同步状态。加仓、减仓、分红等编辑在上层弹窗完成，关闭后回到详情。
- 账户层级：“单账户 / 账户组合 / 管理账户”为同级导航；“记一笔”放在当前账户面板内，随选择的账户切换。管理视图不显示该按钮，没有账户时也不显示。

## 状态与焦点

所有弹窗标题使用各实例独立的 `useId()`，防止嵌套弹窗的 `aria-labelledby` 冲突。详情弹窗不重复显示上层编辑器的写入错误或重试状态。

取消编辑后恢复原详情操作按钮；保存后的刷新可能暂时禁用该按钮，此时把焦点放到仍打开的详情弹窗关闭按钮。关闭详情后恢复持仓行；数据刷新改变页面高度时会将该行带回可见范围。原有 Esc、遮罩关闭、未保存确认和写入中关闭保护继续有效。

## 验证结果

- 后端 `make check`、全包 `make test`（race、shuffle）通过，包含仓库外私有 XIRR 基准；真实现金流未写入仓库。
- 前端 `npm test -- --exclude src/Tax.test.ts`：34 个文件、319 项通过。税务的两项既有失败已在此前的原始版本复现，本次未修改税务代码。
- `npm run build`、`npm run format:check`、`git diff --check` 通过。
- 浏览器使用现有单元测试的合成数据检查 1440px 桌面、390px/360px 手机布局，没有向生产写入测试数据，也未运行前后端 E2E。
- 连续输入空值、整数、带小数点的中间态及完整小数，买入弹窗的高度和顶端位置均保持一致；普通买入和分红保存中同样不改变弹窗尺寸。
- 模拟网络中断后，重试只出现在上层编辑弹窗，重试的请求体与幂等键保持一致；成功后详情保留并展示新记录。
- 桌面详情宽度 1200px，受视口约束；手机详情内滚动、固定可访问的关闭区，窄屏指标为两列，金额完整显示，无页面横向溢出。
- 从账户组合可直接切换到管理账户；单账户记账弹窗对应当前选中的账户。所有浏览器截图为合成数据，保存在仓库外临时目录。
