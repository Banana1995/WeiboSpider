# 多次转入转出时的 XIRR 求解

## 口径与问题

XIRR 求解 `Σ CF[i] / (1+r)^((date[i]-date[0])/365) = 0`，其中 `r > -1`。投资者转入为负，转出为正，期末资产视为末日正现金流；同日先按精确金额净额合并。金额、起止边界、日数和其他收益指标的口径不变。

多次变号表示可能出现多根，不等于已证明多根，更不应直接拒绝正常的反复投入、取出。旧求解器只在原始累计现金流（或反向累计）满足充分条件时处理多次变号，因此会把部分有唯一负收益率的账户挡在求根之前。

## 修正后的求解流程

1. 保留一次变号、原累计现金流及两笔整年现金流的快速路径。
2. 对尚未证明唯一、首尾符号相反的非零收益情况，继续在原有对数区间内寻找候选根。
3. 用候选根附近的正每日折现因子，验证**折现后的累计现金流**是否满足唯一性充分条件。
4. 只有唯一性通过后，才用原有独立认证验证十二位比率和两位百分数的舍入区间，再发布数值。

固定搜索范围、迭代次数、容量限制和取消机制不变。真正的多根、相切根、无解与无法认证的舍入边界不会因增加此路径而被任意选成一个结果。新路径也是充分条件，不是完整的多项式根隔离算法。

## 唯一性与数值证明

令 `d[i]` 为相对首日的整数日数，`q=(1+r)^(-1/365)`，则方程为稀疏多项式 `P(q)=Σ C[i]q^d[i]`。

选取任意正的精确二进制有理数 `q0`，记缩放系数 `A[i]=C[i]q0^d[i]`。假设首项为负（整体乘以负一不改变根），所有真前缀和 `S[k]=Σ(i<=k) A[i] <= 0`，且最终合计 `S[n]>=0`。Abel 求和给出：

`P(q0*u) = S[n]u^d[n] + Σ(k<n) S[k](u^d[k]-u^d[k+1])`。

- 在 `0<u<1`，除以 `u^d[n]` 后严格递增，从负无穷到 `S[n]`。
- 在 `u>1`，上式严格为正。
- 所以整个 `u>0`、等价地整个 `r>-1` 上恰有一个根；最终合计为零时根恰在 `u=1`。

这与折现后剩余投资本金保持非负的 Soper/纯投资条件相联系；负收益也适用。不规则日期可视为没有现金流的日期系数为零，实际实现不展开逐日数组。

浮点候选仅用于找到最多四个邻近探测因子。每个探测因子都是精确可表示的二进制有理数，其整数日幂、金额乘积、前缀合计和最终合计均用 **192 位向外舍入区间**验证。接受不依赖浮点 `exp` 的误差假定、有限网格上只看到一次变号或任意残差容差；近似根仍必须通过原独立舍入认证。

## 验证

- 合成整年现金流 `[-1000,800,-1000,981]` 的收益率为 `-10%`；增长因子的方程可分解为 `-(g-0.9)(1000g²+100g+1090)`，正增长因子上只有一个根，而旧累计条件不能证明它。
- 覆盖正负收益、现金流整体反号和大整数缩放、闰日与不规则间隔，并与独立高精度计算核对。
- 原两根、三根、相切根、舍入中点、取消与容量测试继续有效；补充直接拒绝多根候选的证书测试。
- 实际账户的现金流及独立高精度基准仅放仓库外私有文件。可设置 `LEDGER_XIRR_BASELINE` 运行 `go test -run TestPrivateXIRRBaseline ./internal/modules/ledger`；文件包含 `flows`（`date/amount`）、`expected_value`（十二位比率）、`expected_percentage`（两位百分数）。未提供私有文件时跳过该项，不将实际现金流提交仓库。
