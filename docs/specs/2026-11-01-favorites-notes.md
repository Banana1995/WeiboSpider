# 收藏与笔记

- 每条内容右上角提供“☆ 收藏 / ★ 已收藏”，再次点击取消收藏。微博、雪球、搜索结果、PS 图和收藏与笔记页使用同一收藏状态。
- 原“笔记”标签改为“收藏与笔记”。列表包含已收藏或有划线笔记的未删除内容，同一条内容只出现一次，按原帖发布时间倒序。
- 可组合筛选内容类型（全部 / 收藏 / 笔记）、关键词、平台和原帖发布日期。结束日期包含当天。关键词匹配正文、转发正文、笔记文字及划线摘录；支持两字中文和字面 `%`、`_`。重置恢复全部内容。
- 取消收藏不删除笔记；删除最后一条笔记不取消收藏。移入回收站的内容不在此页显示，恢复后原有收藏和笔记仍在。重新抓取不覆盖收藏状态。

## 存储与接口

`TweetDB` 启动时为已有数据库补建 `favorites(tweet_id PRIMARY KEY, created_at)`，通过外键关联原帖；收藏与抓取数据、划线笔记独立存储。沿用现有服务的共享数据语义。

- `PUT /api/tweets/{id}/favorite`：JSON `{"is_favorited": true|false}`，显式设定状态，可重复请求。未知内容返回 404，无效 JSON 或非布尔状态返回 400。操作写入 `tweet` 类日志。
- 列表、搜索、PS 图、详情和笔记响应附带布尔值 `is_favorited`。
- `GET /api/notes`：保持数组响应；默认返回收藏和笔记的并集。支持 `kind=all|favorites|notes`、`q`（最多 200 字）、`platform=all|weibo|xueqiu`、`start_date`、`end_date`（`YYYY-MM-DD`）。无效筛选返回 400。
- 筛选和刷新只读取数据。评论仍按需加载，抓取状态保持每 3 秒轮询。
