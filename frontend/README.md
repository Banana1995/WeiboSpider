# 白酒行情前端

独立的 Vue 3 + TypeScript + Vite 前端，使用按需引入、异步加载的 ECharts。当前实现行情列表和单品趋势；不修改微博页面或 Python 服务。

## 本地启动

建议使用 Node.js 22 LTS（22.12+）或 24 LTS。本次验证环境为 Node.js 25.2.1。

先在本工作树的 `backend/` 目录启动 Go 服务：

```bash
go run ./cmd/server
```

新库需要显式同步一次；前端不会主动采集：

```bash
curl -X POST http://127.0.0.1:5051/api/platform/liquor/sync \
  -H 'Content-Type: application/json' -d '{}'
curl http://127.0.0.1:5051/api/platform/liquor/sync
```

等待状态为 `succeeded`。随后在 `frontend/` 目录启动前端：

```bash
npm ci
npm run dev
```

打开 <http://127.0.0.1:5173/liquor>，`/` 也显示同一页面。端口固定且冲突时拒绝启动，不占用微博的 5050。开发数据保存在被忽略的 `backend/data/`，不会加入版本控制。

开发代理默认将 `/api/platform/*` 原样转发给 `http://127.0.0.1:5051`。可通过启动 Vite 时的 `BACKEND_PROXY_URL` 改变目标。若后端启用认证，将同一 `BACKEND_API_TOKEN` 通过服务端环境传入 Vite；不要使用 `VITE_*` 变量承载密钥，也不要写入源码。

此代理仅用于本机开发。生产构建不会携带代理配置；正式静态服务需要另外配置同源 API 代理、访问保护和 SPA 回退，API 错误不得回退到 HTML。Vite 开发服务器不能当生产服务。

## 已实现

- 从真实最新行情 API 填充酒品列表，按酒名或规格搜索，点击切换单品。
- 最新价、来源涨跌额、所选区间可用报价首尾差；价格从整数人民币分换算为元。
- 近 7/30/90/365 天，结束日期是来源最新报价日期，不是抓取日期；默认 30 天。
- 请求起止日均包含在内，历史接口显式设置 `limit=366`；按报价日期升序绘图。
- 展示真实覆盖日期和记录数；缺失日保留空值、断开曲线，不插值、不补零。
- 图表触摸/鼠标提示，以及日期倒序的可折叠历史表格。
- 独立的空库、无匹配酒品、历史为空、加载失败和访问拒绝状态。
- 刷新失败保留上次读取的行情；快速切换取消旧请求，旧响应无法覆盖当前选择。
- 15 秒请求超时；组件卸载清理请求、图表实例和尺寸观察器。
- 显示来源报价日期、同步状态及北京时间的最近成功时间；刷新或返回页面时更新非今日报价提示。

“刷新数据”只执行 GET，不触发 POST 同步。同步状态当前在页面加载和手动刷新时读取，不做后台轮询。单点区间不计算首尾变化。来源涨跌额不等同于本平台计算的区间变化。

## 验证

```bash
npm test
npm run build
npm run format:check
```

2026-09-05 本地验证：

- 14 项单元/组件测试通过，覆盖金额、日期、缺失日、搜索与切换、请求竞态、空库、错误保留、超时/取消、跨日标记。组件测试替换图表渲染，真实 Canvas 渲染另在浏览器验证。
- TypeScript 检查和生产构建通过；图表独立分包，入口约 78 kB、图表约 495 kB（压缩前，随版本变化）。
- 实际 Go 进程采集得到 11 款酒、341 条报价；经 Vite 代理在 Chrome 读取与绘图，未使用前端假数据。
- 浏览器验证空库、30 天走势图、切换五粮液、90 天仅有 31 条的覆盖提示、手机搜索、7 天筛选和 7 行历史明细。
- 桌面及 390px 手机模拟视口显示正常，无横向溢出；实际行情请求均为 GET 200，页面控制台无异常。

手机验证为 Chrome 设备模拟，不代表真机 Safari 已测。未做生产 Nginx/Docker 部署或长期稳定性测试。多品对比、涨跌幅归一化和微博前端迁移尚未实现。
